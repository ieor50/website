# IEOR Golden Jubilee website

Static landing page for the Department of Industrial Engineering and Operations Research, IIT Bombay Golden Jubilee.

Registration is handled by the official IIT Bombay event pages:

- Indian Registration: https://www.iitbombay.org/e/ieor-alumni-meet-2026
- International Registration: https://www.iitbombay.org/e/ieor-alumni-meet-2026-usd/
- Reunion events: https://www.iitbombay.org/events/?tag=reunions

The Alumni Meet schedule is available at `/alumni-meet/`. The schedule link opens in a new page from the main programme section.

There is no local registration API or personal data storage in this project.
